## The line

## The angle

The judge penalises the stock jokes — hallucinations, refusals, confident wrong answers — so this roast targets a different, specific flaw every agent owner recognises: a test suite that passes by testing nothing. The punchline lands at the end ("declared the feature done"), and the joke stays playful and self-deprecating, never hateful.
